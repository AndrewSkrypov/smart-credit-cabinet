# 004. Симуляторы внешних систем

Статус: принято; отражает текущую реализацию.

**Контекст.** Для демонстрации нужны реестр, налоговые сведения, БКИ, данные банка,
подписание и АБС. Корпоративные доступы и реальные персональные данные не используются.

**Решение.** `external-sim` предоставляет HTTP-контракты с синтетическими ответами.
ИНН начинаются с `00` и имеют корректные контрольные цифры. Для сценарных компаний заданы
профили; для остальных синтетических ИНН профиль формируется детерминированно.
Пульт позволяет воспроизводить медленный ответ и недоступность.

**Альтернативы.** Реальные платные/закрытые интеграции; встроенные заглушки в `credit`;
записанные ответы только в тестах. Отдельный HTTP-сервис позволяет проверять таймауты
и разрыв сети, сохраняя заменяемость адаптеров.

**Последствия.** Стенд работает без корпоративной сети и подходит для проверки отказов.
Это не подтверждение совместимости с промышленными API или юридической силы подписи.
Управление сбоями — только для демо; внешние маршруты `/ext/` закрывает gateway.
Реестры подписи/выдачи симулятора хранятся в памяти и сбрасываются при перезапуске.

Основание: [интеграции и сценарные компании](../integrations.md),
`services/external-sim/src/main/`.
