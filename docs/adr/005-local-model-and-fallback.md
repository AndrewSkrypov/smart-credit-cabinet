# 005. Локальная модель и работа без неё

Статус: принято; отражает текущую реализацию.

**Контекст.** Помощник должен объяснять продукты и состояние заявки без внешней передачи
финансовых данных. Модель может отсутствовать, отвечать медленно или ошибаться.

**Решение.** По умолчанию ответы формируются правилами из справки и данных заявки.
Необязательный профиль `ai` запускает Ollama с Qwen2.5 3B: на одних и тех же вопросах она
объясняла термины заметно точнее 1.5B. Её лицензия (Qwen Research License) разрешает
исследовательское и некоммерческое использование, чего достаточно для прототипа; для
промышленного запуска модель меняется переменной `ASSISTANT_MODEL` на модель под Apache 2.0
(Qwen2.5 1.5B или 7B) без изменения кода.
Модель используется для общих объяснений; вопросы о конкретной заявке и числовых условиях
обрабатываются правилами. Проверка ответа может заменить его ответом по правилам.
Доступ к заявке выполняется токеном пользователя, переданным в `credit`.

**Альтернативы.** Облачный API, обязательная локальная модель, полностью статическая
справка. Облако добавляет внешнюю передачу данных, обязательная модель увеличивает
требования к памяти и времени запуска, статическая справка хуже объясняет свободный вопрос.

**Последствия.** Основной сценарий работает без весов и GPU. Профиль с моделью требует
отдельной памяти, диска и начального скачивания. Фильтры снижают риск неверного ответа,
но не являются доказательством отсутствия всех ошибок. Помощник не принимает кредитных
решений. История диалога передаётся запросом; отдельной таблицы разговоров нет.
