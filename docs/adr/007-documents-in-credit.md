# 007. Документы принадлежат credit

Статус: принято; отражает текущую реализацию.

**Контекст.** Финансовый документ относится к заявке. Разрешение на чтение зависит от
компании клиента и роли банка; публичная ссылка на файл неприемлема.

**Решение.** Модуль `document` в `credit` проверяет доступ к заявке, тип содержимого,
размер и лимит загрузок. Метаданные хранятся в `documents`, байты — через
порт `FileStore`; базовый Compose использует общий том документов.

**Альтернативы.** Отдельный файловый сервис, байты в PostgreSQL, публичное объектное
хранилище. Отдельному сервису пришлось бы передавать контекст прав; байты в БД увеличивают
её размер; публичные объекты обходят авторизацию кабинета.

**Последствия.** Проверки прав остаются рядом с заявкой. Два контейнера на одном Docker-хосте
видят общий том; для разных хостов нужен общий `FileStore`, например S3-совместимый адаптер,
и проверка его доступности. Резервная копия одной БД недостаточна: нужны также файлы.
Проверка сигнатуры не заменяет антивирусную обработку и полноценную проверку структуры файла.

Основание: `document/DocumentService.kt`, `document/infrastructure/DocumentAdapters.kt`,
[модель данных](../data-model.md).
