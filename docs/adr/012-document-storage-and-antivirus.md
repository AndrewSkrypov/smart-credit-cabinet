# 012. Закрытое хранение документов и проверка до записи

**Контекст.** Несколько экземпляров credit должны одинаково открывать прежние документы
и новые вложения. Переключение хранилища не должно делать старые файлы недоступными.
Проверка расширения и сигнатуры формата не обнаруживает вредоносное содержимое архива.

**Решение.** Сохранить порт `FileStore`, локальный адаптер и добавить адаптер S3 на AWS
SDK 2.55.13. `STORAGE_BACKEND=local|s3` выбирает место новых загрузок. V8 записывает
расположение каждого документа отдельно: прежние строки получают `LOCAL`. Чтение
использует расположение строки, включая после обратного переключения новых загрузок.
Новые документы получают SHA-256; ранее заполненный хэш неизменяем. Прежние миграции
не редактируются. Локальная запись публикует временный файл атомарно после проверки длины.

SeaweedFS 4.48 работает отдельным контейнером в профиле `storage`. Все его данные и
метаданные находятся в постоянном `/data`. S3 не публикуется на хост; WebDAV, Admin UI,
IAM API и каталоги Iceberg/Lance отключены. Учётная запись credit ограничена каталогом
`documents/` своего бакета; оператор имеет отдельные ключи. Клиент получает байты только
через API credit после проверки заявки. Ошибка S3 даёт 503, отсутствующий объект — 404;
при отказе нет скрытой записи в локальное хранилище.

S3 PUT использует фиксированную длину и SHA-256. Проверка реального SeaweedFS обнаружила
отказ части небольших PDF с `payload checksum does not match` при потоковом кодировании
SDK по умолчанию. Регрессия воспроизводилась серией разных PDF на одном клиенте.
Выбор фиксированной длины и SHA-256 устранил отказ; тест сравнивает прочитанные байты
каждого объекта, а не только успешный HTTP-статус. Контроль целостности не отключается.

ClamAV 1.5.4 — отдельный GPL-контейнер, без связывания с приложением. Один порт
`DocumentScanner` вызывается для обычных документов и вложений чата после существующих
проверок размера/формата, до записи объекта, метаданных, журнала и outbox. По TCP передаётся
`INSTREAM`; контейнеру не нужен доступ к тому документов. Вредоносный файл получает
понятный 400 без раскрытия имени антивирусной сигнатуры. Только точный ответ `stream: OK`
разрешает сохранение. Превышение возможностей проверки, сбой протокола, таймаут и
недоступность сканера дают 503. Зашифрованный архив требует снять пароль или выбрать
другой файл. Ограничения распаковки и `AlertExceedsMax` предотвращают незаметную
частичную проверку архива.

До передачи содержимого credit запрашивает `VERSION`. Время сигнатур интерпретируется
в UTC, как и время контейнера. По умолчанию допустим возраст до 72 часов; неизвестная
дата, устаревшая база или дата более чем на пять минут в будущем закрывают загрузку.
`freshclam` обновляет базу в отдельном постоянном томе. Один общий дедлайн ограничивает
проверку версии и сканирование; закрытие сокета прерывает также зависшую запись.

**Альтернативы.** Один глобальный флаг для чтения теряет старое расположение. Публичные
или подписанные ссылки клиенту обходят проверку прав credit. Автоматическая запись
локально при отказе S3 разделяет данные между репликами. Пропуск антивируса при отказе
пропускает непроверенные файлы. MinIO/Redis с несовместимыми условиями лицензирования
не добавляются.

**Последствия.** Миграция должна сравнить размер и SHA-256 исходника и копии до изменения
расположения в БД и сохранить исходники для обратного переноса. Нужна согласованная
остановка записи при backup, включая метаданные SeaweedFS; копировать только объектные
тома работающего сервиса недостаточно. Реализация и проверка переноса/restore учитываются
отдельно от успешной загрузки. Срок хранения файлов, обновление сигнатур и дополнительная
память сканера требуют операционного контроля. Инструкции — в
[runbook хранения](../document-storage.md).

Оператор переноса и backup удерживают общую session advisory lock PostgreSQL.
Перенос останавливает все credit, копирует с проверкой байтов и меняет метаданные
одной транзакцией; атомарно заменяемый закрытый отчёт сохраняет возможность возобновления
после обрыва процесса. Backup включает offline-том SeaweedFS и local; restore принимает
прежний формат 1 и новый формат 2 только в пустом отдельном проекте. Отсутствующий
S3-том при наличии строк S3 и внешний S3 без собственной процедуры копирования дают отказ.
