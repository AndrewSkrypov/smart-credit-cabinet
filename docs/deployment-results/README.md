# Результаты локальной приёмки

Здесь публикуются только очищенные результаты конкретных испытаний. Полные .env,
дампы PostgreSQL, файлы клиентов и JWT из runtime сюда не копируются. Проверки TLS
используют внутренний CA и не доказывают выдачу публичного сертификата на внешнем VPS.

`production-kit.json`: 20 компаний → 20 выдач при prod-лимитах, согласованная копия,
новый пустой проект, проверка API/PDF и отказ повторно перезаписать заполненный проект.
Пиковая наблюдённая сумма Docker stats — 1527447023 байт (около 1457 MiB), без OOM/restart.
Снимки не гарантируют захват мгновенного пика; Docker stats вычитает часть файлового кэша.
Лимиты суммарно 2736 MiB не означают испытание VM, физически ограниченной 4 GiB.

`restore-api.json` — отдельная проверка выданной заявки, старого JWT (401), нового входа,
графика и PDF 600 байт. `restore-integrity.json` — совпадение таблиц/последовательностей
до запуска worker и файлов. `restore-refusal.json` имеет `passed=false` **ожидаемо**:
это сохранённый отказ повторного восстановления в уже заполненный проект. Полный
положительный прогон подтверждён `production-kit.json`.
