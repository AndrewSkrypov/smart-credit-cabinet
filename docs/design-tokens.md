# Дизайн-токены

Визуальный стандарт кабинета взят из публичных страниц банка для бизнеса (alfabank.ru/sme,
/corporate и главная): сводка фирменных цветов, шрифтов, отступов и скруглений. Токены
заданы в одном месте — `frontend/src/theme/theme.ts`; компоненты берут цвета и размеры из
темы, а не пишут их на месте.

| Токен | Значение | Где |
| --- | --- | --- |
| Основной цвет | `#ef3124` | Главные кнопки, активные элементы, акценты |
| Текст | `#030306` с прозрачностью 0,88 | Основной текст |
| Нейтральный | `#898991` | Вторичный текст, неактивные иконки |
| Вторичная кнопка | фон `rgba(15, 25, 55, 0.1)`, текст `#030306` | «Отказаться», «Назад», вторичные действия |
| Тёмный элемент | `#212124` | Тёмные «таблетки», шапка |
| Фон | `#ffffff`; подложка страниц — светло-серая | |
| Поле ввода | заливка `rgba(11, 31, 53, 0.07)`, скругление 4 px сверху, подпись внутри поля | Все поля форм |
| Кнопка | скругление 10 px, высота 48 px (крупная 56 px), без тени | |
| «Таблетка», бейдж | скругление 99 px, 14 px | Статусы заявок |
| Карточка | скругление 24 px, без тени, тонкая граница `#d5d6dc` | Блоки страниц |
| Сетка отступов | 8 px (4, 8, 12, 16, 24, 32, 40, 48, 64) | |
| Типографика | 48 / 40 / 30 / 22 / 18 / 16 / 14 / 12 px; начертания 500, 700; цифры табличные (`tnum`) | Суммы и платежи — `tnum`, чтобы столбцы не прыгали |
| Анимация | 0,2 с, `ease` для кнопок; 0,15–0,2 с `ease-in-out` для ссылок | |

**Шрифт.** На сайте банка — фирменный Alfa Interface Sans с CDN банка. Прототип его не
подключает: шрифт фирменный, а политика безопасности кабинета (CSP) разрешает загружать
только свои ресурсы. Вместо него — открытый Inter (SIL Open Font License) с теми же
начертаниями 500/700 и табличными цифрами; при внедрении в контур банка шрифт заменяется
одной строкой в теме.

**Логотип и иконки банка** не копируются: кабинет — прототип для кейса, а товарные знаки
используются только по согласованию с их владельцем.

**Плитки и иллюстрации.** Лендинг повторяет композицию страниц банка для бизнеса: почти
чёрная полоса (`night` `#121213`) с яркими скруглёнными плитками (`tileSalmon` `#fcb2a8`,
`tilePurple` `#9b3dfa`, `tileCyan` `#a8eef0`, `tileGreen` `#c9f2ad`, `tilePeach` `#ffe4cc`),
затем белый лист со скруглением 80 px, серые плитки продуктов (`tile` `#f3f4f5`), салатовые
карточки задач (`tileLime` `#ecfcb7`) и красный баннер. Иллюстрации банка защищены авторским
правом и в прототип не копируются; вместо них — объёмные Fluent Emoji 3D (MIT) из
`frontend/public/illustrations`, лицензия — в `THIRD_PARTY_NOTICES`. Цифры в плитках берутся
из каталога продуктов, а не задаются в вёрстке.
