Сводки [до](before/summary.json) и [после](after/summary.json) содержат размеры,
число строк DOM, имя загруженного JS, SHA256 каждого PNG и геометрию.
Один изолированный стенд и одинаковые неизменяемые данные; GET правил фиксирует
исторический снимок №11 и первые 11 метаданных, поскольку реальные тесты добавляют
новые версии. Записи БД не удаляются. Демо-кредит создан/подписан/выдан через API;
массовые терминальные строки и уведомления — явно синтетические SQL-фикстуры.

[Геометрия](layout-accept.json): 320/390/900/1024/1440, якоря, reduced-motion,
«Наверх», первая строка маркеров, девять чекбоксов и клавиатура. Scale 200% через
браузерный движок и layout-equivalent viewport записаны с границей доказательства.
[Файлы](frozen-files.json): реальные байты PDF/PDF/XLSX, неизменные SHA256,
отказы 401/404. [Сохранность](preservation-audit.json): 32 пользовательских
контейнера, исходные образы/mount и защищённые входы/миграции/workflow.

U10 **partially_verified**: нативный overscroll/жест пользователя в IAB/на устройстве
не воспроизведён. Статичный PNG, wheel и engine scale этого не доказывают.
Прохождение кодовой/автоматической части допускает review по разделу 8.3 ТЗ;
полное устранение пользовательского эффекта не заявлено.

Результаты повторных прогонов не скрывают первые падения: старый чат-тест ожидал
автоматического применения фоновых изменений, а тест продукта — плоскую фразу
вместо структурированного снимка. Они обновлены под требуемое поведение с
сохранением проверок точного unread, доставки и значения ставки.
Локальный пятисекундный timeout editor-теста при параллельной нагрузке устранён
ограничением workers=2 для запуска, без изменения тайм-аута/утверждений.
