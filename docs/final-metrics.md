# Итоговые метрики финала: измерено и гипотезы

Финал требует отделять измеренные результаты от ожидаемых эффектов. Здесь собраны только
измерения с указанной средой и командой повтора. Гипотезы и способ их проверки на пилоте —
в [исследовании агентского канала](agent-research.md#8-метрики-измерено-и-гипотезы) и
[плане развития](scaling-and-roadmap.md).

## 1. Среда замеров

- Локальный `docker compose up --build` на ноутбуке разработчика (Apple Silicon, Docker Desktop),
  ClamAV в эмуляции x86-64, без модели (`ai` не включён), синтетические демо-учётки.
- Тайминги конвейера — демо-настройки из `.env.example` (`SOURCE_TIMEOUT`, `OFFER_TTL` и т. д.).
  Время ответа симуляторов источников не равно времени реальных ЕГРЮЛ, ФНС и БКИ.
- JSON агентского замера содержит время запуска и идентификатор checkout скрипта.

## 2. Агентский канал от черновика до выдачи

Команда: `python3 scripts/agent-channel-metrics.py --runs 10 --output docs/final-results/agent-channel.json`.
Исторический замер от 26 ноября 2026 года выполнен из checkout `5c86717`.
Скрипт записал этот checkout, фактические ревизии запущенных контейнеров неизвестны.
[Данные замера](final-results/agent-channel.json)

| Метрика | Значение | Что означает |
| --- | --- | --- |
| Успешность сквозного сценария | **10 из 10** | Каждый прогон дошёл до выдачи и кредитного счёта |
| Действия людей на заявку | агент **3**, клиент **4**, банк **0** | Агент: черновик, документ, передача клиенту. Клиент: подтверждение с согласием БКИ, акцепт, код, подпись. Банк: решение автоматическое для этой компании |
| Проверки полномочий | **100 из 100** дали ожидаемый HTTP-код | 90 отказов (`403`, `404`, `409`) и 10 разрешённых чтений кредита агентом (`200`) |
| Подготовка агентом, медиана / p95 | 0,06 / 0,12 с | Время API; время человека на заполнение не входит |
| Решение банка после подтверждения, медиана / p95 | 1,57 / 2,10 с | Конвейер: полнота, источники, скоринг, оффер |
| Выдача после подписи, медиана / p95 | 0,80 / 1,60 с | Симулятор АБС |
| Весь путь в системе, медиана / p95 | 3,43 / 4,47 с | Сумма системного времени без времени людей |

Во всех десяти прогонах роли передали заявку друг другу и дошли до выдачи.
Проверки полномочий сверяли HTTP-коды. Время людей и эффект на реальном потоке
предстоит измерить на пилоте.

## 5. Что не измерено

- Время работы живого агента и клиента с интерфейсом — нужен пилот с наблюдением.
- Нагрузка с сотнями агентов одновременно — оценки в [scaling-and-roadmap.md](scaling-and-roadmap.md).
- Замеры на сервере организаторов — повторить той же командой с `CABINET_URL=https://…`
  на синтетическом стенде.
