## A01–A06

- Поиск, очистка, сортировка и группы сохраняют позицию; только явная страница
  запрашивает один переход после готовности. Polling и явное применение буфера
  не запрашивают переход. Нативное уменьшение документа не перехватывается.
- Один синхронный writer URL на клиентском экране объединяет поправки двух списков.
  Кеш остаётся привязан к фактически полученной странице. Сохранены A → B → A,
  изоляция пользователя/компании, ограниченные запросы и Back/Forward.
- PDF обрабатывает code points целиком. Символ без глифа показан явной записью
  `[U+XXXX]` с пояснением в документе и metadata; это печатное представление,
  не обещание полного покрытия Unicode шрифтом. Снимок/хеш договора и XLSX не меняются.
  Шаблон 2 создаёт отдельные записи. Старые READY ID/байты/checksum/ссылки сохранены;
  retry старого ERROR использует его собственный frozen input, не текущие условия.
- Вход и регистрация отправляются только при готовности. Blur показывает конкретную
  ошибку, исправление снимает её. Согласие обязательно, имя не ограничено кириллицей,
  пароль регистрации соответствует UTF-16/UTF-8 ограничениям backend. Сложность
  существующего пароля при входе не проверяется. Ошибка сети сохраняет ввод/повтор;
  ref исключает две отправки в одном event turn.
- Обычный focus подписи поля нейтрален, error остаётся красным. Брендовые CTA сохранены.
  inputmode ИНН/кода находится на HTML input, сохранены autocomplete и вставка.

## Проверка и ограничения

Адресные unit/DB/E2E выполняются на новой дельте, не засчитываются старым CI.
Этап A локально: frontend 95/95, PDF/pipeline 21/21, браузерные fixtures 8/8
(desktop и эмуляция мобильной ширины), ESLint, TypeScript и production build прошли.
Проверен также retry старого PREVIEW после выдачи: фаза и frozen input сохранены.
Локальные журналы и фактический чеклист находятся в `../pr1-final-followup` и
пользовательском deliverables вне Git. Опубликованный SHA и итоговый CI будут
зафиксированы отдельно после решения о публикации.
Браузерные ответы этого пакета — явно изолированные UI fixtures: они не меняют
пользовательские компании, аккаунты, переписку или read cursor. Кредитный pipeline
проверяется отдельными PostgreSQL integration tests. PDF отрендерены Poppler и
просмотрены; проверены emoji, CJK-нотация, обычный текст и многостраничный перенос.

Настоящие iPhone/Safari/встроенная клавиатура и Android Chrome не проверены.
Эмуляция мобильной ширины Edge не выдаётся за проверку устройства. V01 требует
показа реального мобильного кандидата и обратной связи до распространения общей
геометрии кабинетов. Финансовая модель, PCI04, DLP/OCR и новый помощник не входят.
Merge, auto-merge и force-push не выполняются.
