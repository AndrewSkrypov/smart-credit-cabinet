## Изменения

- C01: компактная «Наверх» справа, safe-area, клавиатура и reduced-motion сохранены.
  На лендинге помощник не отображается; кнопку не добавляли в кабинеты.
- C02: отдельная полоса canSign под шапкой удалена. В профиле клиента показаны
  доступность подписи и пояснение; в подписании — сообщение представителю без
  полномочий. canSign, роли и серверная авторизация не изменены.
- C03: запрос другой страницы сохраняет высоту списка и пагинации. Старые строки
  не становятся кликабельной новой выборкой, известные счётчики сохраняются;
  при новом поиске неизвестные значения отображаются как ожидание. Статус
  обновления/ошибки занимает постоянное место в инструментах. История версий
  показывает пять записей на страницу без второго вертикального scroller.
- C04: возвращены последовательные непустые разделы клиента «В работе» и
  «Завершённые». У каждого ограниченный серверный запрос и своя страница;
  поиск и сортировка общие. Колонки main 8/4, карточки, представители,
  промоблок и привычные CTA сохранены. Полный список сотрудников доступен
  через действие внутри карточки, без отдельного блока между карточками.
- C05: вкладки, фильтры, прежняя таблица/мобильные карточки и страницы размещены
  в существующей панели main. Размеры строк и ширина таблицы сохранены.
  Пустая группа не означает отсутствие заявок в остальных группах.
- CACHE: ответ с фактической первой страницей сохраняется под её ключом до
  исправления URL; старый кеш первой страницы больше не заменяет этот ответ.
- SCROLL: явное перелистывание прокручивает один раз после результата, с учётом
  реального размера закреплённой шапки. Возврат из карточки восстанавливает
  позицию после готовности компоновки; polling и unread не запускают прокрутку.

## Ограничения

Одна нативная прокрутка HTML сохранена. Перехват wheel/touch, искусственная
инерция, scroll-snap, body overflow:hidden и глобальный overscroll:none не
добавлены. У workspace убрана искусственная полоса градиента высотой 120 px;
шапка рисует собственную подложку, документ использует фон страницы. Для
лендинга и split AuthFrame сравниваются края и resize старой/новой политики.

Headless Edge, синтетическое колесо и эмулированный touch не доказывают устранение
исходного субъективного ощущения в IAB/на устройстве пользователя. Эта часть
остаётся открытой до пользовательского просмотра. Отменённое удаление фона
изображения не выполнялось. Финансовая модель, сравнение версий «было/стало»,
OCR/DLP и остальные отложенные этапы в пакет не добавлены. Соответствие PCI DSS
не заявляется.

Во время локальных проверок сохраняются main, старые preview 18130/18140
и сервисы пользовательского preview 18150. Сравнительный frontend кандидата
работает отдельно на 18153 с API собственного followup-стенда; main-сравнение —
18152. Почта followup включена: проверки MAIL=off выполняются штатным CI,
а локально почтовые сценарии принимаются отдельным MAIL-профилем.
