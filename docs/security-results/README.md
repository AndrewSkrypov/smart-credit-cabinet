# Сохранённые проверки безопасности

JSON в этом каталоге — результаты конкретного локального запуска 22.10.2026.
Они не заменяют повторный запуск и CI на финальном SHA. Даты, SHA, image ID,
версии базы и ограничения находятся в самих отчётах и [описании безопасности](../security.md).
Отчёты с сессионными JWT, секретами и кодами подписи сюда не переносятся.
