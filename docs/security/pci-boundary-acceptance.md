# Приёмка дополнения PCI к cabinet-polish

Вход — [неизменяемое ТЗ](../plans/pci-boundary-mini-spec-2026-10-24.md), SHA256
`6997d4192b0cc0d190e699a2597564291277b2a350c1867f2bdb65ef6c178989`.
Дополнение включено пользователем 24.10.2026 в текущий goal; исходные P00–P29 и хеш
plan-v3 не менялись. Координатор и владелец текущей дельты FE/документов/P22–P25 —
исполнитель cabinet-polish; чужие checkout не изменялись.

Объём: PCI00–PCI03 и относящийся к ним PCI05. PCI04 отложен до начала реализации:
для его 3–5 часов отдельной приёмки нет подтверждённого окна без задержки обязательных
P22–P29. Серверного запрета PAN в этом кандидате нет.

Уточнение заказчика «мокай» принято отдельно: назначения и канал PCI03 демонстрационные.
Требование реальных оперативных контактов остаётся ограничением перед эксплуатацией;
оно не выдаётся за выполненное. Tabletop подтверждает только проверенные действия на синтетике.

Адресная проверка воспроизводится на отдельном синтетическом стенде с доступным
антивирусом: из `e2e` выполнить `CABINET_URL=http://localhost:8080 npx playwright test pci-boundary.spec.ts`.
Установленный Chromium — стандарт; локальная проверка использовала Node 20.20.2 и канал Edge.
Playwright сохраняет снимки и безопасные метаданные tabletop в HTML-отчёт; trace и
автоматические screenshots сценария отключены. Содержимое сценария и карточные номера
в отчёт не добавляются. Репетиция выполняет обычную отправку/публикацию синтетических
объектов, проверки доступа и отсутствие штатного удаления; не отключает аудит и
не утверждает удаления из backup, логов или внешней модели.

Первый прогон нового теста имел две ошибки тестовой подготовки: общий браузерный
контекст разных ролей и ожидание 201 вместо действующего 200 для чата. Исправлен
только новый тест; HTTP-контракт и реализация чата сохранены. Принятый повтор — 4/4.

Оценка PCI DSS, формальное исключение из scope, DLP/OCR и удаление производных копий
не выполнялись. Успешный UI-тест предупреждения не доказывает запрет сохранения PAN.
