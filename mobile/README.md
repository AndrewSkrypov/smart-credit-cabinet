# Мобильное приложение кабинета

Два способа поставить кабинет на телефон. Оба открывают стенд `https://credit-cabinet.ru`:
данные и логика остаются на сервере, приложение всегда показывает текущую версию.

## Без сборки: экран «Домой»

iPhone: Safari → кабинет → «Поделиться» → «На экран „Домой“». Android: Chrome → меню → «Установить приложение».
Кабинет открывается на весь экран с иконкой «Кабинет»; срок действия не ограничен.

## Нативная оболочка iOS (бесплатный Apple ID)

Нужны Mac с Xcode и вход в Xcode → Settings → Accounts.

1. На iPhone включить «Режим разработчика»: Настройки → Конфиденциальность и безопасность.
2. Подключить разблокированный iPhone к Mac.
3. `bash mobile/scripts/install-ios.sh` (выбрать телефон: `IPHONE=<UDID>`, список — `xcrun devicectl list devices`).
4. Первый запуск: Настройки → Основные → VPN и управление устройством → доверять разработчику.

Бесплатная подпись действует 7 дней: переустановите приложение накануне показа той же командой.
Платный Apple Developer нужен только для TestFlight и App Store — проект к этому готов, меняется команда подписи.

Другой стенд, например локальный по Wi-Fi: `CABINET_APP_URL=http://<ip-mac>:8080 bash mobile/scripts/install-ios.sh`.
Без связи приложение показывает страницу `www/offline.html` с кнопкой «Повторить».

## Android

`npm run android:apk` в каталоге `mobile/` собирает APK с отладочной подписью
(`android/app/build/outputs/apk/debug/app-debug.apk`); нужны Android SDK (`ANDROID_HOME=~/Library/Android/sdk`)
и JDK 21 (`JAVA_HOME=$(/usr/libexec/java_home -v 21)`): Java 25 из Android Studio Gradle 8.14 не поддерживает.
APK передаётся файлом и ставится с разрешением «Установка из неизвестных источников».

## Как устроено

Capacitor 8 открывает стенд в WebView (`server.url` в `capacitor.config.ts`): тот же источник, поэтому
не нужен CORS и работают потоковые ответы помощника. Иконки и заставка — `assets/`, проекты Xcode
и Android Studio — `ios/` и `android/`. Для публикации в магазинах веб-часть стоит упаковать в приложение
и разрешить на сервере источник `capacitor://localhost`.
