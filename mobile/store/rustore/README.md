# Публикация в RuStore

Карточка приложения «Кабинет» для консоли разработчика RuStore (console.rustore.ru).
Публикует владелец аккаунта разработчика: регистрация, подтверждение личности и модерация
проходят в консоли, обычно от одного до пяти рабочих дней.

## Сборка

```bash
CABINET_ANDROID_SIGNING=~/.android-keys/pump-cabinet-release.properties bash mobile/scripts/build-android-release.sh
```

- В RuStore загружается `mobile/android/app/build/outputs/bundle/release/app-release.aab` (или APK из
  `frontend/public/downloads/kabinet.apk`).
- Пакет `ru.creditcabinet.pump`, версия `1.0.0` (`versionCode 1`). Каждое обновление увеличивает
  `versionCode` в `mobile/android/app/build.gradle`.
- **Ключ подписи** лежит вне репозитория: `~/.android-keys/pump-cabinet-release.jks` и файл параметров
  рядом. RuStore принимает обновления только с тем же ключом — сохраните оба файла в защищённое место
  (например, Vault команды). Без них новое обновление не опубликовать.
- После публикации впишите ссылку на карточку в `frontend/public/downloads/apps.json`
  (`android.rustoreUrl`) — на странице `/app` появится кнопка «Скачать в RuStore».

## Тексты карточки

**Название:** Кабинет — кредит для бизнеса

**Краткое описание (до 80 символов):** Заявка на кредит для ИП и малого бизнеса, статус и подпись в телефоне

**Полное описание:**

Кабинет предпринимателя: подбор кредита, заявка, решение банка и подписание договора — без визита в офис.

- Подбор продукта под задачу и расчёт платежа до заявки.
- Статус заявки и понятный следующий шаг: что нужно от вас прямо сейчас.
- Документы, переписка с банком и напоминания в одном месте.
- Подписание договора кодом, график платежей и транши по кредитной линии.
- Агенту — портфель закреплённых клиентов и заявки по предодобренным предложениям; согласие на запрос
  в бюро, отправку и подпись всегда делает сам клиент.

Демонстрационная версия команды PUMP для Альфа Хак 2026: все компании и данные синтетические.

**Категория:** Финансы · **Возраст:** 18+ · **Сайт:** https://credit-cabinet.ru
